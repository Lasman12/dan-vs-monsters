# דן נגד המפלצות 👊

משחק פלטפורמה בפיקסל ארט. דן לא צריך סיבה — הוא פשוט רוצה להרביץ לכל המפלצות. כי בא לו.

**לשחק:** https://lasman12.github.io/dan-vs-monsters/

- 10 שלבים ארוכים, עם נקודות שמירה (דגלים), פארקור (טיפוס על קירות, קפיצים, פלטפורמות זזות, בלוקים מתפוררים) וקצת אסטרטגיה (ידיות ודלתות, אבירים עם מגן, גובלינים שמסתערים).
- בוס בסוף כל שלב, ומדליה (ארד / כסף / זהב) אחרי כל ניצחון.
- חנות: שריון, נשק, לבבות, קפיצה כפולה, דאש ושיקויים.
- כל שחקן יוצר חשבון (שם משתמש + סיסמה) וההתקדמות שלו נשמרת בדפדפן.

## שליטה
| מקש | פעולה |
|---|---|
| ← → / A D | תזוזה |
| רווח / W / ↑ | קפיצה |
| J / X | הרבצה (↓ + J באוויר = מכה למטה) |
| K / Shift | דאש |
| Q | שיקוי |
| Esc | עצירה |
| M | סאונד |

בטלפון מופיעים כפתורי מגע.
